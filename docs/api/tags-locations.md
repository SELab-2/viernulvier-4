# Tags & Locations

## 🏷️ Tags
### [GET] `/tag`
Returns all tags.

### [GET] `/tag/:tagId`
Returns a specific tag.

## 📍 Locations
### [GET] `/location`
Returns all locations.

### [GET] `/location/:locationId`
Returns a specific location.

### [POST] `/location`
Creates a location. (**Security:** `apiKey` required)
